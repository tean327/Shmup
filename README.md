This Project is a shmup style game made with C# and godot. I implemented a special feature which is that when the special cooldown is done you can maintain the special feature touch to launch a laser beam from you, with this laser you can grab enemies and blocks, once the element is grabed you can either use it as a shield (but be careful because it will only take one hit before exploding) or you can just throw it by releasing the special feature touch. I highly recommend to play with a controller because this game was created with a controller experience in mind (if you play with keyboard the controls of the player will be a little bit to much, because I coded them with the strengh of the input and a keyboard is either 0 (not pressed) or 1 (pressed) while a joystick can be more or less in a direction, also the pause menu can be tricky on the keyboard because the touch to enter it is also the same touch to valid your choice so when entering it you will click the first button (who has the focus and is the continue button, leading you to quit the menu). If you really can't play with controller in order to enter the pause menu you have to maintain the space bar then either click on some other button than continue or press the down arrow then you can released the space bar.
